# ADR-0015: MIT license

Status: Accepted
Date: 2026-08-05

## Context

No `LICENSE` file existed, which defaults to "all rights reserved" — not the intent for a public portfolio repo meant to be read and learned from.

## Decision

Added MIT, attributed to Akshat Kankani.

## Alternatives considered

Apache-2.0 was the other reasonable option (it adds an explicit patent grant) and lost only because MIT is the simpler default for something educational rather than something facing commercial/patent concerns. Not a strong technical call either way — easy to swap later if preferences change.

Staying with no license was the status quo and just left things ambiguous for no reason.

## Consequences

Low-stakes, one-file change, no code implications. Made as a default judgment call rather than something worth stopping to ask about.
