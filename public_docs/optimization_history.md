## Future Work
*   3.0 (flat array price levels, replacing `std::map`) is the next planned step, and the one most likely to finally test the cache-miss hypothesis directly with hardware counters.
*   2.0's absolute numbers above should be re-measured on an idle machine before being treated as authoritative; the relative comparison is sound regardless.
*   The per-category variation noted in 2.0's takeaway (why Instruction Delivery vs. Instruction Processing improves more in different workloads) is an open question 3.0's data should help answer.
